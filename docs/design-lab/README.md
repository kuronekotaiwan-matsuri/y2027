# design-lab

黒猫台湾まつり2027のデザインシステムを選ぶための、使い捨ての比較ツール。
サイト本体（`src/`）からは独立しており、ビルド不要でブラウザだけで動く。

> **選定結果**: 第1ラウンドで 02・07・09 を選び、第2ラウンド（v2）の **案02「机の上の商店街」** を採用した。
> 確定値は `docs/design-system.md` に移してある。このフォルダは候補の記録として残している。

## 使い方

1. `docs/design-lab/index.html` をブラウザで開く（ダブルクリックで可）
2. 上部のセレクトボックス、または数字キー（1〜9, 0）と ← → で案を切り替える
3. 「並べて見る」でモバイル幅と PC 幅を同時に、「10案一覧」で全案をサムネイルで比較する
4. 「新しいタブで開く」で見本ページ単体を全画面で見る（URL 末尾の `#03` などで案を指定できる）

Google Fonts を読み込むため、インターネット接続が必要。

## 構成

```text
docs/design-lab/
├─ index.html          切り替え・並列表示のコントローラ
├─ sample.html         見本ページ（このサイト固有の部品を1ページに並べたもの）
├─ lab.css             見本ページの共通スタイル。10案で共通。トークン以外の値を直書きしない
├─ themes.js           10案の一覧（id・名前・説明）
├─ tokens/
│  ├─ tokens-01.css    案01 のデザイントークン（CSS custom properties）
│  └─ ... tokens-10.css
├─ v2/                 第2ラウンド。同じ構成で独立して動く
│  ├─ index.html
│  ├─ sample.html
│  ├─ lab.css
│  ├─ themes.js
│  └─ tokens/
└─ README.md
```

見た目の差は、すべて `tokens/tokens-XX.css` のカスタムプロパティで表現している。
`lab.css` は固定で、トークンを差し替えるだけで10案が切り替わる。
これは本番サイトの `globals.css`（トークン）+ コンポーネント CSS と同じ構造。

## 見本ページに入っているもの

サイト仕様書（`docs/specification.md`）の部品を一通り並べている。

- ヘッダー、ヒーロー（現在地の表示、開催予定、CTA）
- 最新の記録（記録カード）
- 物語一覧（物語カード。公式と個人の区別）
- できるまで（月区切り、物語バッジ、立場バッジ、状態タグ、ゴールマーカー、物語フィルタ）
- 記録ページ（個人活動の注記、本文、スマホ写真、手書きメモ、引用、Instagram リンクカード、前後の記録）
- 部品一覧（ボタン、タグ、バッジ、色見本、文字）
- フッター

画像はすべて CSS のプレースホルダー。実写真は入れていない。

## 10案の方向性

2026年の世界観（Zen Maru Gothic、赤・サーモン・ゴールド）をどこまで残すか、
「作っている途中の空気」をどう出すかを軸に振っている。

| 案 | 名前 | 2026年との距離 | 途中の空気の出し方 |
|---|---|---|---|
| 01 | 継承 | そのまま | なし（基準） |
| 02 | 方眼ノート | 色は同じ | 手書き見出し、方眼紙、ノートの罫線 |
| 03 | ジン／ざら紙 | 赤は残す | マーカー文字、太い黒線、ハード影、テープ |
| 04 | 夜市 | 赤とゴールドを残しダークに | 提灯の光、夜の屋台 |
| 05 | 花磚（台湾タイル） | 赤に青緑を足す | 幾何学タイル、直線的 |
| 06 | サーモン | 2026年の副色を主役に | 大きな角丸、手書きの日付 |
| 07 | 付箋とテープ | 色は同じ | ペン字、傾いたカード、付箋、ポラロイド枠 |
| 08 | 編集部 | 赤を最小限に | 明朝、細い罫線、雑誌の紙面 |
| 09 | 商店街レトロ | 赤に紺を足す | 判子、二重線、日よけの縞 |
| 10 | 芽吹き | 赤に若葉色を足す | 点線のつる、葉の形のドット |

## 選定後の受け渡し

1. 採用した `tokens/tokens-XX.css` の `:root` を、そのまま `src/app/globals.css` のトークン定義にする
2. 同じ値を `docs/design-system.md` に書き出す
3. `docs/design-lab/` は削除してよい（git の履歴に残る）。候補の記録として残してもよい

案を組み合わせたい場合は、トークンファイルを1つ複製して値を差し替え、`themes.js` に追加すれば11案目として比較できる。
