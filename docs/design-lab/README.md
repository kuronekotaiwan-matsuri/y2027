# design-lab

黒猫台湾まつり2027のデザインシステムを選ぶための、使い捨ての比較ツール。
サイト本体（`src/`）からは独立しており、ビルド不要でブラウザだけで動く。

> **選定結果**: 第1ラウンドで 02・07・09 を選び、第2ラウンド（v2）の **案02「机の上の商店街」** を採用した。
> 確定値は `docs/design-system.md` に移してある。このフォルダは候補の記録として残している。

## 使い方

1. `docs/design-lab/v1/index.html`（第1ラウンド）または `docs/design-lab/v2/index.html`（第2ラウンド）をブラウザで開く（ダブルクリックで可）
2. 上部のセレクトボックス、または数字キー（1〜9, 0）と ← → で案を切り替える
3. 「並べて見る」でモバイル幅と PC 幅を同時に、「10案一覧」で全案をサムネイルで比較する
4. 「新しいタブで開く」で見本ページ単体を全画面で見る（URL 末尾の `#03` などで案を指定できる）

Google Fonts を読み込むため、インターネット接続が必要。

## 構成

```text
docs/design-lab/
├─ README.md           この文書（両ラウンド共通）
├─ v1/                 第1ラウンド（10案）
│  ├─ index.html       切り替え・並列表示のコントローラ
│  ├─ sample.html      見本ページ（このサイト固有の部品を1ページに並べたもの）
│  ├─ lab.css          見本ページの共通スタイル。10案で共通。トークン以外の値を直書きしない
│  ├─ themes.js        10案の一覧（id・名前・説明）
│  └─ tokens/
│     ├─ tokens-01.css 案01 のデザイントークン（CSS custom properties）
│     └─ ... tokens-10.css
└─ v2/                 第2ラウンド（10案）。同じ構成で独立して動く
   ├─ index.html
   ├─ sample.html
   ├─ lab.css
   ├─ themes.js
   └─ tokens/
```

見た目の差は、すべて `tokens/tokens-XX.css` のカスタムプロパティで表現している。
`lab.css` は固定で、トークンを差し替えるだけで10案が切り替わる。
これは本番サイトの `globals.css`（トークン）+ コンポーネント CSS と同じ構造。

## 見本ページに入っているもの

サイト仕様書（`docs/specification.md`）の部品を一通り並べている。

- ヘッダー、ヒーロー（現在地の表示、開催予定、CTA）
- 最新の記録（記録カード）
- 物語一覧（物語カード。公式と個人の区別）
- できるまで（月区切り、物語バッジ、立場バッジ、状態タグ、ゴールマーカー、物語フィルタ）
- 記録ページ（個人活動の注記、本文、スマホ写真、手書きメモ、引用、Instagram リンクカード、前後の記録）
- 部品一覧（ボタン、タグ、バッジ、色見本、文字）
- フッター

画像はすべて CSS のプレースホルダー。実写真は入れていない。

## 選定後の受け渡し

1. 採用した `tokens/tokens-XX.css` の `:root` を、そのまま `src/app/globals.css` のトークン定義にする
2. 同じ値を `docs/design-system.md` に書き出す
3. `docs/design-lab/` は削除してよい（git の履歴に残る）。候補の記録として残してもよい

案を組み合わせたい場合は、トークンファイルを1つ複製して値を差し替え、`themes.js` に追加すれば11案目として比較できる。

## v3: 「誰が書いたか」「どこに来たか」の見せ方（2026年9月）

第2段階の実装後、記録カードの「物語バッジ・立場バッジ・状態タグ」が多すぎて初見で分からない、という指摘を受けて作った第3ラウンド。
色や書体（v2 で確定済み）は変えず、**情報の見せ方**だけを案にしている。

- `v3/index.html` をブラウザで開く。既定の「全案を並べる」で、全案がモバイル幅で横に並ぶ。「場所」ボタンで全案を同じ場所（できるまで／記録／トップ／人たち／書き手ページ）へ移動できる
- 「1案を詳しく」でモバイル幅と PC 幅を同時に見る
- 構成は v2 と違い、案の差はトークンではなくマークアップ。同じデータ（`data.js`）を案ごとの描画関数（`variants.js`）で描く

```text
v3/
├─ index.html     コントローラ
├─ sample.html    見本ページの枠（中身は render.js が描く）
├─ data.js        見本データ（書き手・物語・記録）。全案で共通
├─ variants.js    案ごとの描画関数（カード、記録ページ、トップ、人たち、書き手ページ）
├─ render.js      ハッシュ（#02 や #02/record）で案を選んで描画
├─ tokens.css     v2 案02 のトークン（確定値）
└─ lab.css        v2 の共通スタイル + v3 の部品（顔、署名、吹き出し、書いた人カードなど）
```

案:

| 案 | 見せ方 | 参考にしたもの |
|---|---|---|
| 00 | 現状（比較用）。バッジ3種と物語チップ | いまのサイト |
| 01 | 署名。顔なし、右下にペン字で「― 池田（実行委員）」 | デイリーポータルZ、Burning Man Journal |
| 02 | 顔と名前。先頭に顔・名前・立場、末尾に「書いた人」 | note、Instagram、GitHub の役割ラベル |
| 03 | 吹き出し。顔の横に吹き出しで「〇〇が書きました」 | CAMPFIRE の活動報告、LINE |
| 04 | 顔と名前だけ。立場はカードに出さない | Instagram |
| 05 | 02 + 顔で絞る。物語チップの代わりに顔を並べる | — |
